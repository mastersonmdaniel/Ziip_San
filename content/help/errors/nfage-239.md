# Versão do XML não suportada

O cabeçalho do XML declara uma versão de leiaute que a SEFAZ não aceita mais (ou ainda não aceita).

## Causas prováveis

- O documento foi montado numa versão de leiaute fora de vigência.

## O que fazer

- Reenvie o documento: o sistema monta na versão vigente do leiaute.
- Se a rejeição persistir para todos os documentos, abra um chamado — a vigência do leiaute pode ter mudado.
