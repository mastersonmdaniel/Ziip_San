# Competência anterior à autorização de uso dos emissores

A data de competência informada na DPS é anterior à data de autorização de uso dos emissores registrada no CNC (Cadastro Nacional de Contribuintes) do município emissor para este contribuinte. O município ainda não tinha autorizado este prestador a usar os emissores nacionais naquela competência.

## Causas prováveis

- A prefeitura registrou no CNC uma data de autorização posterior à competência da nota.
- A competência foi informada para mês anterior ao credenciamento do prestador.

## O que fazer

- Peça ao município para conferir/ajustar a data de autorização de uso no CNC do prestador.
- Não mude a competência só para passar: ela é o mês em que o serviço foi prestado; resolva o cadastro primeiro.
