# Município emissor sem convênio

O código do município emissor informado na DPS não existe no cadastro de convênio municipal do Sistema Nacional: esse município não emite pelo padrão nacional (ou o código está errado).

## Causas prováveis

- O código IBGE do município emissor foi digitado com erro.
- O município ainda não aderiu ao Sistema Nacional.

## O que fazer

- Confira o código IBGE do município do endereço de prestação (P1.3).
- Se o município não é conveniado, a nota deve seguir o sistema próprio dele, fora do padrão nacional.
