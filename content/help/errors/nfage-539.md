# Duplicidade com chave diferente

Já existe documento autorizado com o mesmo emitente, modelo, série e número, mas com chave de acesso diferente. É a duplicidade mais séria: o mesmo número foi usado para um documento com conteúdo diferente.

## Causas prováveis

- O número foi reutilizado depois de uma emissão que já tinha sido autorizada com outros dados.
- Houve emissão do mesmo número por dois canais (sistema e contingência) com dados diferentes.

## O que fazer

- Não reenvie: consulte o documento já autorizado e confira qual conteúdo vale.
- Se o documento autorizado está errado, cancele-o ou substitua-o pelo fluxo próprio — nunca emita o mesmo número de novo.
