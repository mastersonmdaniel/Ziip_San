# IE do destinatário não cadastrada

A inscrição estadual informada para o destinatário não existe no cadastro da SEFAZ.

## Causas prováveis

- A IE do destinatário foi digitada com erro.
- A IE do destinatário foi baixada.

## O que fazer

- Confira a IE com o destinatário e corrija o cadastro do cliente.
- Se a IE foi baixada, trate o destinatário como não contribuinte, se for o caso.
