# Município não parametrizado para os emissores nacionais

O município emissor informado na DPS não está parametrizado para utilizar os emissores públicos nacionais, conforme a parametrização dele no Sistema Nacional NFS-e. Ou seja: esse município não emite pelo Emissor Nacional — usa sistema próprio.

## Causas prováveis

- O município não aderiu aos emissores públicos nacionais (só compartilha dados, ou nem isso).
- O município emissor informado na DPS está errado.

## O que fazer

- Emita a nota pelo sistema próprio da prefeitura desse município.
- Se o município deveria estar no Emissor Nacional, confira a parametrização dele no painel municipal do Sistema Nacional.
