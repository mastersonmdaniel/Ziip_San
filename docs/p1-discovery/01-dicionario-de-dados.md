- **Sem dado pessoal real.** Nomes, documentos, endereços, telefones e
  e-mails nunca entram aqui; matrícula real nunca entra aqui — usa-se
  o código substituto (ver
  [roteiro de anonimização](../seguranca/roteiro-anonimizacao-piloto.md)).

  mapeamento (template 02) e para a P1.2.
